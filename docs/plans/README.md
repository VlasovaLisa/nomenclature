# План выполнения ТЗ «Поиск номенклатур и сравнение позиций запроса клиентов с номенклатурами поставщика»

Источник требований: [../tech-task.pdf](../tech-task.pdf).

## Цель

MVP веб-приложения, которое по текстовому запросу клиента находит в справочнике МТР (2022 и 2023 годы, НГП) три наиболее подходящие позиции труб. Поиск гибридный: семантический поиск на Sentence Transformers плюс сравнение четырёх обязательных характеристик (тип трубы, диаметр, толщина стенки, марка стали). Если точного соответствия нет, система формирует предполагаемую конфигурацию по одному шаблону.

Целевые показатели:

| Метрика | Порог |
|---|---|
| Hit Rate@3 | ≥ 60% |
| Точность извлечения 4 параметров | ≥ 80% |
| Время поиска после загрузки модели | ≤ 5 с (CPU) |
| Развёртывание по README.md | ≤ 30 мин |

### Зависимости

```
1 Данные ─► 2 Тестовая выборка + TF-IDF ─► 3 Извлечение ─┐
                                    └────► 4 Семантика ───┴─► 5 Гибрид ─► 6 Веб ─► 7 Сдача
```

Этапы 3 и 4 не зависят друг от друга, их можно вести параллельно.

Почему тестовая выборка идёт вторым этапом, а не в конце: ТЗ требует, чтобы выборка не использовалась при настройке алгоритма. Если собрать её после подбора регулярок и весов, она будет подогнана под алгоритм, и метрика окажется завышенной.

## Принятые решения

- **Хранилище — файлы** (parquet и `.npy`), без БД: полноценная БД вне границ MVP (§8).
- **Без FAISS.** На 701 вектор хватает косинусного сходства на numpy, лишняя зависимость не нужна.
- **Фронтенд — серверные шаблоны Jinja** без SPA. ТЗ требует форму, строку поиска, кнопку и таблицу, для этого хватает обычного HTML.
- **Логика отделена от Flask** (`core/`), чтобы `evaluate.py` и тесты работали без веб-сервера.

## Данные

Справочники лежат в `data/`. Разбор данных — в [../data-analysis.md](../data-analysis.md). Главное:

- цифры ТЗ подтверждены: листы `НГП` и `ОБС, НКТ` обоих годов дают 1794 записи и 701 уникальную пару;
- настоящая марка стали есть только в ~15% наименований, чаще вместо неё стоит класс прочности (`К52`). Четвёртый параметр трактуем как «марка стали / класс прочности» — **нужно согласовать с заказчиком**;
- шаблон для генерации: `Труба {тип} группа {N} {D}х{S} {класс} ТТТ-01.02.04-01`;
- системный Python 3.9, а нужен 3.10+, поэтому окружение создаём через `uv`.
