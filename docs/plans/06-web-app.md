# Этап 6. Веб-интерфейс

**Срок:** 14.12–18.12.2026

## Цель

Сделать Flask-приложение, через которое менеджер загружает справочник, вводит запрос и видит три результата с совпадениями, различиями и заменами.

## Пункты ТЗ

- §6 п. 1, 3, 8–10: загрузка XLSX, ввод запроса, top-3 с различиями, замены, уведомление.
- §6: форма загрузки справочника, поисковая строка, кнопка поиска, таблица результатов.
- §7 п. 3, п. 7: ≤ 5 с, работа в Chrome и Firefox.
- §8 п. 1–2.
- Риск №6: результаты показываются как рекомендации.

## Задачи

- [x] `app/__init__.py`: фабрика `create_app(config, encoder)`. Модель, справочник (`catalog.parquet`, а если его нет — сборка из `data/*.xlsx`) и кеш эмбеддингов загружаются один раз при старте. В тестах кодировщик подменяется.
- [x] Логика вынесена из Flask: `core/catalog.py` (`prepare_catalog`, `add_specs` — перенесены из скрипта), `core/service.py` (`NomenclatureService`: держит справочник и ранжировщик; новый справочник подменяется целиком и только после успешной обработки).
- [x] `app/routes.py`:
  - [x] `GET /` — страница с формой загрузки и строкой поиска;
  - [x] `POST /upload` — один или несколько XLSX, проверка расширения, лимит 20 МБ, обработка через `prepare_catalog`, пересчёт параметров и эмбеддингов, сообщение «загружено N пар». Загруженный справочник действует до перезапуска (полноценная БД вне MVP);
  - [x] `GET /search?q=` — GET вместо POST: результат можно открыть по ссылке и вернуться кнопкой «Назад».
- [x] Шаблон `app/templates/index.html`:
  - [x] таблица: наименование, 4 параметра (✓ / ✗ / ? плюс цвет, чтобы читалось и без цвета), замены;
  - [x] строка «Распознано в запросе» с извлечёнными параметрами;
  - [x] пометка «Предполагаемая конфигурация — требует проверки, не подтверждена поставщиком» и отдельная пометка, если группа взята у ближайшей позиции;
  - [x] уведомление «Точного совпадения в справочнике не найдено»;
  - [x] подпись, что результаты — рекомендации.
- [x] Ошибки: пустой запрос, не-XLSX, повреждённый файл, нет нужных столбцов, нет труб — понятное сообщение, код 400, текущий справочник не меняется.
- [x] Время поиска на странице.
- [x] Проверено в Chrome (реальная модель): поиск, новая комбинация, узкий экран 420 px (таблица прокручивается вбок), загрузка двух реальных справочников (0.2 с при попадании в кеш) и отказ для не-XLSX.
- [ ] **Проверить в Firefox вручную** — инструмента для Firefox нет; это требование ТЗ §7 п. 7.
- [x] `tests/test_app.py` — 9 тестов: страница, точное совпадение с заменами, генерация с уведомлением, подсветка различий, пустой запрос, загрузка справочника, отказы для не-XLSX, файла без столбцов и повреждённого файла.

Запуск: `.venv/bin/flask --app app run` → http://127.0.0.1:5000.

## Definition of Done

- Через браузер можно загрузить оба справочника и выполнить поиск.
- В выдаче три результата, различия видны, замены выведены, сгенерированные позиции явно помечены.
- Работает в Chrome и Firefox.
