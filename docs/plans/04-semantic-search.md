# Этап 4. Семантический поиск

**Срок:** 05.12–08.12.2026

## Цель

Подобрать компактную предобученную модель Sentence Transformers, заранее посчитать эмбеддинги справочника и реализовать быстрый поиск top-K кандидатов на CPU.

## Пункты ТЗ

- §5 п. 2, §6 п. 5, §8 п. 5: семантический поиск предобученной моделью.
- §7: без обучения с нуля; эмбеддинги справочника считаются заранее и сохраняются.
- §7 п. 3, п. 5: ≤ 5 с на поиск, работа без GPU.
- Риск №5: компактная модель и предрасчёт эмбеддингов.

## Задачи

- [x] Сравнены 3 модели на dev-выборке (`evaluate.py --algo semantic --model ... --queries dev`): `paraphrase-multilingual-MiniLM-L12-v2`, `multilingual-e5-small`, `rubert-tiny2`.
- [x] Выбрана `intfloat/multilingual-e5-small` (лучшая по HR@1 и MRR на dev, 5 мс на запрос). Таблица и причины — в `docs/results.md`.
- [x] Нормализованный текст лучше исходного для всех трёх моделей; кодируем нормализованный (`--raw-text` оставлен для сравнения).
- [x] `core/semantic_search.py`:
  - [x] модели описаны в `MODELS` (`ModelConfig`: id и префиксы), по умолчанию `DEFAULT_MODEL = "e5-small"`; кодировщик передаётся снаружи (в тестах — фейковый);
  - [x] эмбеддинги нормализуются, поиск — скалярное произведение на numpy;
  - [x] интерфейс `search(query, k)` как у TF-IDF;
  - [x] recall@10 на dev = 100%, поэтому для гибрида K=30 — с запасом (константа появится в ранжировщике на этапе 5).
- [x] Кеш эмбеддингов `EmbeddingCache`: файл `data/processed/embeddings_<model>_<norm|raw>.npz` с отпечатком (sha256 от модели, префикса, режима текста и списка наименований). При изменении справочника кеш пересчитывается.
- [x] `scripts/build_embeddings.py`: заранее считает кеш для модели по умолчанию.
- [x] Работа без интернета проверена: после первого скачивания модели `HF_HUB_OFFLINE=1` работает. В README нужно написать: первый запуск скачивает ~470 МБ в `~/.cache/huggingface`.
- [x] Время на CPU: загрузка модели 2.5–5 с, эмбеддинги справочника 1 с, поиск 5–12 мс.
- [x] Прогон на тестовой выборке записан в `docs/results.md`.

## Definition of Done

- Поиск одного запроса после загрузки модели занимает заметно меньше 5 с на CPU (ориентир < 0,5 с, чтобы оставить запас на ранжирование).
- Повторный запуск не пересчитывает эмбеддинги без изменения справочника.
- Есть результат semantic на тестовой выборке.
