# Этап 3. Нормализация текста и извлечение характеристик

**Срок:** 29.11–04.12.2026

## Цель

Привести наименования к единому виду и надёжно извлекать четыре обязательных параметра: тип трубы, диаметр, толщину стенки и марку стали. Точность извлечения на тестовых запросах — не менее 80%.

## Пункты ТЗ

- §4.2, разовая подготовка, п. 2–3: нормализация и выделение характеристик.
- §4.2, автоматическая обработка, п. 2: нормализация запроса.
- §5 п. 3: регулярные выражения, словари сокращений, правила.
- §6 п. 4, §8 п. 3, §3.2 п. 2.
- Риски №2 и №4.

## Входы

- Заметки по данным с этапа 1 (`docs/data-analysis.md`).
- Dev-выборка с этапа 2. Тестовую выборку для подбора правил не используем.

## Задачи

- [x] `core/normalize.py`:
  - [x] нижний регистр, `ё → е`, схлопывание пробелов;
  - [x] единый разделитель размеров: `x`, `х`, `*`, `×` → `х`;
  - [x] десятичная запятая → точка внутри чисел;
  - [x] латинские буквы, похожие на кириллицу (`K52`, `x`) → кириллица;
  - [x] словарь сокращений `core/abbreviations.py`: `тр.`, `б/ш`, `бесш.`, `э/с`, `эл/св`, `эл.св.`, `электросв.`, `обс.`, `гр.`, `гр.пр.`, `ст.`, `исп.`, `внутр.`, `наружн.`, `усил.`. Сокращения `г/д`, `х/д`, `вгп` не добавлены: в справочнике нет таких типов труб.
- [x] `core/extract.py`:
  - [x] dataclass `PipeSpec(pipe_type, diameter, wall_thickness, steel_grade)`, все поля опциональные; `compare` / `mismatches` для этапа 5;
  - [x] тип трубы — по ключевым словам, при опечатке — нечёткое сравнение слов (`difflib`, порог 0.8);
  - [x] диаметр и стенка — регулярное выражение на пару `D х S`;
  - [x] четвёртый параметр: класс `К..`, затем марка стали; для обсадных, НКТ и НКМ — группа прочности (см. [../results.md](../results.md));
  - [x] `extract_pipe_group` — `группа N` для шаблона на этапе 5;
  - [x] тесты на формы обсадных труб (`ОТТМ-114х7,4-Е`, `Б-Д-168х7,3-Б`, `Дс1-168х8,9`, `BC-177,8х9,19-R3-N80`).
- [x] Параметры и группа предрасчитаны в `catalog.parquet` (`scripts/prepare_data.py`).
- [x] Покрытие справочника: все 4 параметра у 517 из 521 наименования; у оставшихся 4 марки и класса нет в тексте. По ходу исправлены ложные срабатывания: размер `89х6` принимался за марку стали, марка бралась из оговорки «исключая марку стали…».
- [x] `tests/test_normalize.py`, `tests/test_extract.py` — 54 теста на строках справочника и искажённых запросах.
- [x] `evaluate.py`: точность извлечения и доля top-1 с несовпадающими параметрами. Test: 100%, dev: 100%. Оценка оптимистична, см. оговорку в results.md.

## Definition of Done

- Точность извлечения на тестовой выборке ≥ 80% (4 параметра × 20 запросов).
- Все тесты pytest проходят.
- Покрытие справочника посчитано и записано.

## Риски

| Риск | Что делаем |
|---|---|
| Опечатка в ключевом слове типа трубы ломает словарь | Нечёткое сравнение по расстоянию Левенштейна для слов типа (небольшой порог) |
| Неоднозначные числа (ГОСТ, длина трубы путаются с размерами) | Сначала вырезаем ГОСТ/ТУ и длину, потом ищем пару `D х S` |
| Подгонка правил под тестовую выборку | Правила подбираем только на справочнике и dev-выборке |
