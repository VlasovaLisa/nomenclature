## Сверка с ТЗ

Если взять листы `НГП` и `ОБС, НКТ` обоих годов, отбросить пустые строки и две мусорные строки (в 2023 / ОБС, НКТ в наименовании стоит дата `2026-09-14`), получается:

- **1794 записи** — совпадает с ТЗ;
- **701 уникальная пара** «Наименование – Замены» — совпадает с ТЗ;
- 521 уникальное наименование.

Правило очистки: брать только строки, где наименование начинается с «Труб».

**Вывод:** настоящая марка стали указана лишь в ~15% наименований. В основном вместо неё стоит класс прочности (`К52`) или группа прочности (`Д`, `Е`). Если понимать «марку стали» из ТЗ буквально, порог точности извлечения 80% для четвёртого параметра теряет смысл: в большинстве записей извлекать нечего. Предложение: четвёртый параметр — **«марка стали / класс прочности»**, то есть одно из: марка стали, класс прочности `К..`, группа прочности обсадных труб. Решение нужно согласовать с заказчиком.

## Поле «Замены»

- Варианты разделены словом ` или ` (в 1027 из 1794 записей).
- В 199 записях варианты склеены без разделителя: `...00186654-2019Труба бесшовная...`. Разделять по началу слова «Труба» после цифры.
- Встречаются хвостовые `, ,` — убирать.

Итог разбивки (`core/loader.py`): 1182 варианта замен; у 223 пар один вариант, у 475 — два, у 3 — три. Делим только по «или» перед словом «Труба» и по склейке перед «Труба»: «или» внутри примечаний («по ТУ X или ТУ Y», «наличия или отсутствия контроля») разделителем не считается. В 4 записях НКТ замена начинается со слов «Насосно-компрессорные трубы НКТВ…» — это нормальное наименование.

## Сокращения

В самом справочнике наименования почти полные: бытовых сокращений вроде `э/с`, `б/ш`, `тр.` нет. Встречаются в основном обозначения стандартов и исполнений:

| Обозначение | Количество | Смысл |
|---|---|---|
| `ТУ`, `ГОСТ`, `ТТТ` | 893, 583, 365 | Нормативные документы |
| `ОТТМ`, `ОТТГ`, `ТБО`, `Батресс`, `BC` | 83, 36, … | Тип резьбового соединения обсадных труб |
| `НКТ`, `НКТВ`, `НКМ` | 74, 4, 6 | Насосно-компрессорные трубы (В — с высаженными концами) |
| `ППУ`, `МП` | 32, 18 | Пенополиуретановая изоляция, металлическая оболочка |
| `KCU`, `KCV` | 70, 60 | Ударная вязкость — относится к примечаниям, а не к параметрам |
| `PSL`, `RC`, `EW` | 18, 12, 4 | Обозначения по API/ГОСТ 31446 |

**Вывод для этапа 3:** словарь сокращений нужен прежде всего для запросов клиентов, а не для справочника. Его составляем по типичным сокращениям менеджеров (`тр.`, `э/с`, `эл/св`, `б/ш`, `бесш.`, `г/д`, `х/д`, `ст.`, `обс.`) и по искажениям из dev-выборки.

## Шаблон для предполагаемых конфигураций

Самая частая форма (339 наименований) — шаблон заказчика `ТТТ-01.02.04-01`:

```
Труба {тип} группа {N} {D}х{S} {класс прочности} ТТТ-01.02.04-01
```

Примеры: `Труба бесшовная группа 4 114х8 К52 ТТТ-01.02.04-01`, `Труба электросварная группа 2 1020х12 К52 ТТТ-01.02.04-01`.

Шаблон покрывает только бесшовные и электросварные трубы. Для обсадных и НКТ конфигурации не генерируем — по ТЗ поддерживается один шаблон (§5, §8).

Открытый вопрос: «группа N» в шаблоне есть, а в четырёх обязательных параметрах её нет. Если в запросе группа не указана, подставляем `группа не указана` и помечаем это в результате, либо делаем группу пятым, необязательным параметром.
