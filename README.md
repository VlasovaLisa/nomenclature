# Поиск номенклатуры

Веб-приложение для сопоставления запроса клиента со справочником материально-технических ресурсов (МТР). По текстовому наименованию трубы оно показывает три наиболее подходящие позиции справочника, отмечает совпадения и различия по четырём параметрам (тип трубы, диаметр, толщина стенки, марка стали / класс прочности) и выводит варианты замен. Если точной позиции в справочнике нет, система формирует предполагаемую конфигурацию по шаблону.

Учебный проект, ПГНИУ, 2026. Техническое задание — [docs/tech-task.pdf](docs/tech-task.pdf).

## Как это работает

1. Запрос нормализуется: регистр, `х/x/*` в размерах, сокращения `б/ш`, `эл/св`, `гр.` и т. д.
2. Из запроса извлекаются 4 параметра (регулярные выражения и словари).
3. Нейросетевая модель `intfloat/multilingual-e5-small` отбирает 30 близких по смыслу позиций справочника.
4. Кандидаты сортируются так, что технические параметры важнее текстового сходства: сначала меньше несовпадений, затем больше совпадений, затем совпадение группы, затем сходство по смыслу.
5. Если точного соответствия нет, первой строкой идёт конфигурация `Труба {тип} группа {N} {D}х{S} {К..} ТТТ-01.02.04-01` с пометкой «требует проверки». Шаблон применяется только к бесшовным и электросварным трубам с классом прочности.

Результаты — рекомендации: окончательное решение о соответствии принимает пользователь.

## Требования

- Python **3.10 или новее** (проверено на 3.10 и 3.12). Проверить: `python3 --version`.
- ~2 ГБ на диске (зависимости и модель), GPU не нужен.
- Интернет только для первой установки: зависимости и модель (~470 МБ) скачиваются один раз.
- Браузер Chrome или Firefox.

## Установка и запуск

Команды выполняются из корня проекта.

**1. Окружение и зависимости**

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

На Linux без видеокарты сначала поставьте CPU-сборку PyTorch, иначе pip скачает CUDA-версию (несколько гигабайт):

```bash
pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

Если системный Python старше 3.10, можно поставить нужную версию через [uv](https://docs.astral.sh/uv/): `uv venv --python 3.12 .venv`, затем `uv pip install -r requirements.txt`.

**2. Данные**

Справочники `2022год_НГП.xlsx` и `2023год_НГП.xlsx` лежат в `data/`. Подготовка объединяет их, удаляет дубликаты и извлекает параметры:

```bash
python scripts/prepare_data.py
```

Ожидаемый вывод: `Записей после очистки: 1794`, `Уникальных пар «Наименование – Замены»: 701`.

**3. Модель и эмбеддинги**

При первом запуске модель скачивается в `~/.cache/huggingface` (~470 МБ). Затем считаются эмбеддинги справочника (около секунды):

```bash
python scripts/build_embeddings.py
```

После этого интернет не нужен. Чтобы явно запретить обращения к сети, задайте `HF_HUB_OFFLINE=1`.

**4. Запуск приложения**

```bash
flask --app app run
```

Откройте http://127.0.0.1:5000. Старт занимает несколько секунд: загружается модель.

Через форму «Справочник» можно загрузить другие XLSX-файлы со столбцами «Полное наименование МТР» и «Замены». Загруженный справочник действует до перезапуска приложения.

## Проверка качества

```bash
pytest                                                    # модульные тесты
python scripts/evaluate.py --algo hybrid --queries test   # итоговый алгоритм
python scripts/evaluate.py --algo tfidf  --queries test   # базовый TF-IDF для сравнения
python scripts/evaluate.py --algo hybrid --queries test -v  # top-3 по каждому запросу
```

Доступны алгоритмы `tfidf`, `semantic`, `hybrid` и выборки `test` (замороженная, 20 запросов) и `dev` (для настройки, 17 запросов).

Итоговые метрики на тестовой выборке:

| Метрика | TF-IDF | Hybrid | Требование ТЗ |
|---|---|---|---|
| Hit Rate@3 | 93% | **100%** | ≥ 60% |
| Hit Rate@1 | 87% | **100%** | — |
| Точность извлечения 4 параметров | 100% | 100% | ≥ 80% |
| Новые комбинации: конфигурация с сохранёнными параметрами | — | **5 из 5** | обязательно |
| Время поиска (CPU) | < 1 мс | ≤ 35 мс | ≤ 5 с |

Подробности, эксперименты и ограничения оценки — в [docs/results.md](docs/results.md).

## Структура проекта

```
app/                   Flask: маршруты и шаблон страницы
core/                  логика, не зависящая от веба
  loader.py            чтение и очистка XLSX
  normalize.py         нормализация текста, abbreviations.py — словарь сокращений
  extract.py           извлечение параметров (PipeSpec)
  tfidf_search.py      базовый поиск
  semantic_search.py   нейросетевой поиск и кеш эмбеддингов
  ranker.py            гибридное ранжирование
  config_builder.py    предполагаемая конфигурация по шаблону
  evaluation.py        метрики
data/                  исходные справочники; processed/ — подготовленные данные; test/ — выборки
scripts/               подготовка данных, эмбеддинги, оценка
tests/                 pytest
docs/                  ТЗ, планы, анализ данных, результаты
```

## Ограничения MVP

- Поддерживаются 4 параметра; ГОСТ/ТУ, покрытия и группа прочности учитываются только через текстовое сходство.
- Предполагаемые конфигурации строятся по одному шаблону и не являются подтверждёнными позициями поставщика.
- Варианты замен выводятся из справочника как есть, без проверки взаимозаменяемости.
- Нет авторизации, базы данных, интеграции с ERP и автоматического обновления справочников.
